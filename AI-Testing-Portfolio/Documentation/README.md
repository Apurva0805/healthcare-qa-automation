# Documentation

This folder contains the documentation for the AI-assisted healthcare QA portfolio.

## Documents
- `AI_Testing_Approach.md` – objective, scope, tools, workflow, and quality controls.
- `AI_TestCase_Review.md` – review method and findings template for AI-generated patient-registration test cases.

## Usage
Keep the approved requirements and actual test evidence as the source of truth. Record assumptions and clarification items instead of allowing AI to invent business rules.
