# Prompts

This folder contains reusable prompts for AI-assisted healthcare QA work.

## File
- `QA_Prompt_Library.md` – prompts for requirement analysis, test generation, test-case review, Playwright Java/TestNG code generation, debugging, AI-output evaluation, and traceability.

## Safe usage
- Use approved, non-confidential requirements.
- Use dummy patient data only.
- Never paste production credentials, patient identifiers, access tokens, or confidential records.
- Verify AI output against source requirements and the real project code before using it.
