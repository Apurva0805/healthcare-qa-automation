\# Healthcare QA Automation Portfolio



\## Project Overview

A healthcare-focused QA automation portfolio demonstrating manual testing knowledge, UI automation, API testing, SQL validation, AI-assisted testing, and CI/CD.



\## Technology Stack

\- Java

\- Playwright

\- TestNG

\- Maven

\- Page Object Model (POM)

\- REST Assured

\- SQL

\- Apache POI / Excel

\- PromptFoo

\- Git and GitHub

\- GitHub Actions



\## Project Modules



\### 1. UI Automation – Patient Registration

\- Automated patient registration workflows.

\- Positive and negative test scenarios.

\- Mandatory field validation.

\- Patient demographic validation.

\- Visit information validation.

\- Page Object Model implementation.

\- Test execution using TestNG and Maven.



\### 2. API Testing

\- REST API testing using REST Assured.

\- GET, PUT, and DELETE request coverage.

\- API response validation.



\### 3. SQL Practice

\- Healthcare-related SQL queries.

\- Patient and billing data validation.

\- JOIN operations and data verification.



\### 4. Excel-Based Testing

\- Patient registration test cases.

\- Test data management.

\- AI-generated test case review.



\### 5. AI-Assisted QA

\- Prompt engineering for test case generation.

\- AI-generated test script review.

\- PromptFoo evaluation configuration.

\- Human review of AI-generated test scenarios.



\### 6. CI/CD

\- GitHub Actions workflow.

\- Automated Maven test execution.

\- Playwright screenshot artifact upload.



\## Framework Structure



\- `src/test/java` – Test framework and test classes

\- `AI-Testing-Portfolio` – AI testing documentation and evaluation

\- `testdata` – Test data

\- `screenshots` – Failure screenshots

\- `.github/workflows` – CI/CD workflow

\- `pom.xml` – Maven dependencies and configuration
